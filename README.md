# Gym Management System

## Introduction
Gyms are an essential part of our lives, providing exercise and body-building facilities. However, managing gym records manually is challenging and inefficient. Our **Gym Management System** aims to digitalize and streamline gym management operations, providing an easy-to-use platform for gym members, trainers, and administrators.

This web-based system allows users to search workout and diet plans, manage subscriptions, and track their membership status. Additionally, trainers and administrators can manage plans and member details seamlessly.

## Features
- **User Management:** Register, login, and manage personal profiles.
- **Subscription Plans:** View and subscribe to various gym plans.
- **Workout & Diet Plans:** Search, view, and choose workout/diet plans.
- **Trainer Management:** Trainers can manage workout and diet plans.
- **Admin Controls:** Admins can add/remove trainers, manage members, and oversee gym operations.
- **Quick Search:** Non-registered users can explore gym facilities, programs, and blogs.

## Technologies Used
- **Frontend:** React.js
- **Backend:** Java Spring Boot
- **Database:** MySQL
- **IDE:** Eclipse, VS Code, MySQL Workbench

## Functional Requirements
### 1. User Account
- Users sign up by providing personal details.
- Login authentication is required.
- Users can view and subscribe to membership plans.

### 2. Registration & Profile Management
- Users must register to access services.
- Existing users can log in and manage their memberships.

### 3. Trainer Account
- Admins create trainer accounts.
- Trainers can log in and manage workout and diet plans.

### 4. Admin Account
- Admins have full access to user and trainer management.
- Admins can add/remove membership plans and trainers.

### 5. Quick Search
- Non-registered users can explore gym facilities, locations, and programs.
- View blogs on fitness and health awareness.
